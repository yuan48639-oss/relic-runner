# 遗迹奔跑者 Demo

这是一个 Godot 4 小型 2D 动作闯关 Demo 原型，目标是逐步打磨到可以公开试玩、后续可提交 Steam Demo 审核的质量。

## 当前范围

- 引擎：Godot 4.x
- 首发目标：Windows
- 输入：键盘、鼠标、Xbox 兼容手柄
- 内容：可行走家园、大型横向卷轴关卡、摄像机跟随、8 个短关卡、二段跳、冲刺、近战攻击、陷阱、钥匙门、移动平台、易碎平台、巡逻/飞行/盾兵/爬虫/Boss 敌人、死亡/复活/通关流程
- 经济：金币持久保存；踩怪、剑杀、技能击杀会生成金币掉落，金币会吸附到玩家身上
- 装备：背包药水、武器、靴子、护甲、护符；购买后会显示在玩家身上
- 技能：Boss 可掉落炎爆术；`O` 打开技能列表，`K` / `L` 释放已装备技能
- 存档：`user://savegame.json` 保存金币、生命上限、背包、购买物、装备、技能等
- 局域网：当前只有主机/加入连接外壳，尚未实现玩法同步

## 本地运行

1. 安装 Godot 4.x。
2. 用 Godot 打开 `game/` 目录。
3. 点击运行。主场景是 `res://scenes/Main.tscn`。

当前仓库包含项目文件和脚本，尚未做正式导出包。

## 操作

- 移动：`A/D`、方向键、左摇杆、十字键
- 跳跃/二段跳：`Space`、`W`、上方向键、手柄 A
- 冲刺：`Shift`、手柄 B
- 攻击/交互：`J`、鼠标左键、手柄 X
- 使用背包药水：`Q`、手柄 Y
- 打开背包/装备栏：`I`
- 打开技能列表：`O`
- 释放已装备技能：`K`、`L`
- 暂停：`Esc`、手柄 Start
- 重开当前关：`R`
- 语言：通过 `Language / 语言` 按钮切换

## 当前玩法规则

- 默认进入家园。玩家需要走到设施旁按 `J` 或鼠标左键交互。
- 家园设施包括：商店、晨辉核心、背包/装备栏、远征门、告示牌/系统菜单。
- 每次远征都从第 1 关开始，中途通关会进入下一关，最终通关才回到家园。
- 生命归零会显示死亡通告，可选择返回家园，或花 100 金币在检查点复活。
- 当前本地测试版本会给至少 `99999` 金币，方便购买装备和测试。
- 踩怪奖励 2 金币；剑杀奖励 1 金币，并有 10% 概率掉落生命药水。
- 金币会以掉落物形式弹出、下落、吸附到玩家身体，然后入账并播放金属音。
- Boss 会掉落炎爆术。拾取后可装备到 `K` 或 `L`，释放时对范围内敌人造成火焰伤害。
- 生命药水默认回复 1 点生命；医者护符会让药水回复 2 点，并提高剑杀掉药概率到 25%。
- 金币护符让每次击败敌人额外获得 1 金币。
- 晨辉核心生命上限升级价格：50、85、120 金币。
- 家园商店价格：药水 6、长剑 18、迅捷靴 28、青铜护甲 34、金币护符 40、医者护符 52、羽翼靴 68、晨辉刃 82。

## 当前美术语义

- 蓝色移动平台：升降/横移踏板，只绘制平台本体。
- 蓝色检查点旗子：已从运行时移除，之后需要更清晰的检查点美术再恢复。
- 金色旗/门：关卡出口。
- 红色三角：尖刺陷阱。
- 玩家、敌人、武器、装备和技能目前是程序化占位美术，已经具备动态和装备外观，但正式上架前应替换为授权或自制精细素材。
- 背景为项目自制程序化分层 2D 场景，包括天空层、云、日光、远山、遗迹剪影、道路和草。

## UI 导航

- 家园设施靠近后按 `J` 或鼠标左键打开。
- 家园打开的菜单可按 `Esc` 返回。
- 背包/装备栏可在家园或远征中按 `I` 打开。
- 技能列表可按 `O` 打开，并能把已解锁技能装备到 `K` / `L`。
- 菜单支持 `WASD`、方向键、`J`、`Enter`、`Space` 操作。

## 局域网原型

主菜单/家园系统中包含局域网原型入口。当前可以创建 ENet 主机、加入 `127.0.0.1`、停止网络连接，但还不是完整联机玩法。
